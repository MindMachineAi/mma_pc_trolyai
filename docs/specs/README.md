# Đặc tả cho Cline

Mỗi file `<ten>.md` là một việc. Giao việc cho Cline bằng câu: `Làm docs/specs/<ten>.md`.

Khung: Mục tiêu · Hiện trạng · Nguyên tắc bắt buộc · Việc cần làm (đánh số, nêu file + hành vi) ·
Biến môi trường · Không làm · Nghiệm thu (đánh số, kiểm được trên preview) · Người dùng cần chuẩn bị.
